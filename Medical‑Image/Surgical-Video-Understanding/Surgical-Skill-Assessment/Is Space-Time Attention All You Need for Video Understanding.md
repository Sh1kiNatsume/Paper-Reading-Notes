## 1. 背景与问题

论文研究的问题是：能否不用卷积网络，而完全依靠空间与时间上的自注意力，构建有效的视频分类模型？

作者指出，视频与文本都是序列数据。短时间片段中的动作，有时需要结合视频其他时刻的内容才能理解。自注意力可以直接建立远距离位置之间的联系；相比之下，卷积更偏向局部计算，扩大感受野通常需要堆叠更多层。

卷积的局部连接、平移等变性等归纳偏置，在数据量有限时有帮助；但在数据充足时，也可能限制模型的表达能力。与此同时，深层 CNN，尤其是用于视频的 3D CNN，训练开销较大。论文因此尝试将 ViT 的 patch-token 思路拓展到视频，并比较多种降低时空注意力计算成本的方式。

论文还探索了长视频建模：模型可以处理 96 帧的片段；在 HowTo100M 实验中，单个片段覆盖约 102.4 秒。

## 2. 核心方法

### 2.1 输入与整体架构

TimeSformer 以 ViT 为基础，但不是把视频当作单张图片处理。它将视频的每一帧切成不重叠的图像块，将每个图像块线性映射为 token，加入时空位置编码，再送入 Transformer 编码器。分类时使用可学习的分类 token 表示整段视频，并接分类 MLP。

论文默认使用 ViT-Base 架构；默认视频输入为 8 帧、每帧裁剪为 224×224，patch 大小为 16×16。每帧因此包含 14×14 个 patch。

ViT 的 Transformer 层通常包含注意力子层和 MLP 子层，二者都有残差连接。注意力并非直接作用于原始像素：输入先经 LayerNorm，再通过线性投影生成 Q、K、V；注意力输出也会经过投影。MLP 通常由两层线性层和 GELU 激活构成。

### 2.2 分离式时空注意力

论文比较了五种注意力方案。作者最终采用 **Divided Space-Time Attention（T+S，分离式时空注意力）**：每个 Transformer 块内，先做时间注意力，再做空间注意力，然后通过 MLP。
![5种注意力比较](../../../Assets/Is%20Space-Time%20Attention%20All%20You%20Need%20for%20Video%20Understanding/Fig2.png)
- **时间注意力**：对同一空间位置在不同帧中的 token 做注意力计算。
- **空间注意力**：对同一帧中的不同空间位置做注意力计算。
- 时间注意力与空间注意力使用各自的 Q、K、V 投影参数。
- 时间注意力的输出作为后续空间注意力的输入。

因此，“分离”是指把原本对所有帧、所有空间位置同时计算的联合时空注意力，拆成每层先跨帧、再帧内计算的两个步骤。

下面的张量变形展示了核心实现思路。这里省略分类 token、位置编码、残差、LayerNorm 和 MLP，仅展示注意力分别沿哪一维计算：

```python
# x: [B, T, N, C]
# B: batch，T: 帧数，N: 每帧 patch 数，C: 特征维度

# 时间注意力：固定 patch 位置，沿帧维度 T 计算
z = x.permute(0, 2, 1, 3).reshape(B * N, T, C)
z = temporal_attention(z)
x = z.reshape(B, N, T, C).permute(0, 2, 1, 3)

# 空间注意力：固定帧，沿 patch 维度 N 计算
z = x.reshape(B * T, N, C)
z = spatial_attention(z)
x = z.reshape(B, T, N, C)
```

论文报告，分离式注意力每个 patch 所需的注意力比较数为 $N+F+2$；联合时空注意力则为 $NF+1$。随着帧数或分辨率增加，分离式计算更容易扩展。

## 3. 创新点

- 将 ViT 的 patch-token 架构拓展到视频，构建完全以自注意力为基础的视频分类模型。
- 提出并实验比较多种时空注意力模式，发现“先时间、后空间”的分离式注意力在论文所测方案中效果最好。
- 通过分解注意力计算，使模型能处理更高分辨率和更长的视频片段。
- 探索将模型应用于长时视频任务，而不只处理常见的短片段动作分类。

### 4.4 预训练与训练设置

论文使用 ImageNet-1K 或 ImageNet-21K 预训练 ViT，再将其用于视频模型。附录指出，时间与空间注意力层以 ViT 对应的注意力层权重初始化。TimeSformer 默认训练 15 个 epoch，初始学习率为 0.005，并在第 11、14 个 epoch 将学习率降为原来的十分之一；训练使用 32 张 GPU 的同步 SGD。

## 5. 个人思考

这篇论文的重点不只是把图像 Transformer 用在视频上，而是明确处理视频的两类关系：同一时刻不同位置之间的空间关系，以及同一位置不同时间之间的时间关系。分离式设计依次计算这两类关系，既保留时空建模能力，也避免对所有时空 token 做一次完整的联合注意力。

论文的结果也提示，视频任务对时序信息的依赖程度不同：Kinetics-400 较容易受场景和外观线索帮助；Something-Something-V2 更需要复杂的时间推理。因此，只用空间注意力在前者上仍有较好表现，在后者上的效果则明显下降。

## 后续阅读问题与记录

### TimeSformer 能处理一分钟以上的视频吗？

可以。论文在 HowTo100M 长视频任务中测试了最多 96 帧的输入；在该实验的抽帧设置下，单片段覆盖约 102.4 秒。论文也报告，增加输入帧数通常能提高准确率。

### 为什么把视频和文字类比为序列？

二者都可以表示为有顺序的元素序列。论文用这个类比说明，短片段的动作可能需要结合其他时刻的信息才能消歧；自注意力可以直接让远距离位置交换信息。

### 卷积的归纳偏置、感受野和计算开销分别指什么？

- **归纳偏置**：卷积的局部连接和平移等变性等结构性假设。在数据较少时可能有利于学习；数据充足时，过强的先验也可能限制模型可表示的函数。
- **感受野**：某个特征能够利用的输入区域。卷积层通常先处理局部邻域，要整合远距离信息往往需要堆叠多层。
- **计算开销**：论文指出，深层 CNN 和视频 3D CNN 的训练开销较大；TimeSformer 通过预训练及分离式注意力降低论文实验中的训练或推理成本。该结论是论文对所比较模型和设置的实验结果，不代表所有场景下 Transformer 都比 CNN 便宜。

### ViT 有卷积吗？输入是否经过线性层？

ViT 通常不使用传统 CNN 那样逐层提取特征的卷积网络，但包含多处可学习的线性映射：

1. 每个 patch 先展平，再线性映射成 token embedding。该映射也常用 `Conv2d(kernel_size=patch_size, stride=patch_size)` 实现；数学上它相当于对不重叠 patch 做线性投影。
2. Transformer 注意力内部用线性层生成 Q、K、V，并对多头结果做输出投影。
3. MLP 包含两层线性层，中间接 GELU。
4. LayerNorm 通常带有可学习的缩放与偏移参数；残差相加本身不含可学习参数。

因此，“无卷积”不是“没有线性层”，而是模型不依赖传统 CNN 的卷积特征提取层。

### 每层是不是先 LayerNorm，再做 Q、K、V？

是。TimeSformer 论文给出的注意力计算中，输入表示先经过 LayerNorm，再分别通过可学习的线性映射得到 Q、K、V。分离式注意力块则先对时间注意力执行这一过程，再用时间注意力更新后的表示计算空间注意力，最后经过 MLP。时间与空间注意力使用各自的投影参数。


1.适用于长于1分钟的视频
2.视频和文字都是序列数据 短片段的动作需要跟其他视频片段上下文化 
3.卷积网络有较强的归纳偏置 小数据优 数据充足场景限制模型表达能力 ，感受野问题，适合小范围的时空建模 虽然GPU硬件发展迅速但是训练深层CNNs依然开销大

# TimeSformer 这几步在做什么

## 1. 视频块与索引

视频被切成许多图像块。$(p,t)$ 表示第 $t$ 帧里第 $p$ 个空间位置的块；$N$ 是每帧的块数，$F$ 是帧数。$\ell$ 表示 Transformer 层，$a$ 表示注意力头。

## 2. Q、K、V 如何得到

每个块当前的特征表示 $\mathbf{z}$ 分别经过三个可学习的线性映射，得到查询、键和值：

$$
\mathbf{q}=W_Q\operatorname{LN}(\mathbf{z}),\quad
\mathbf{k}=W_K\operatorname{LN}(\mathbf{z}),\quad
\mathbf{v}=W_V\operatorname{LN}(\mathbf{z}).
$$

它们都是向量，不是文字或标签。粗略地说，$\mathbf{q}$ 和 $\mathbf{k}$ 用于判断该关注谁，$\mathbf{v}$ 是之后要汇总的信息。

## 3. 注意力权重怎么算

当前块的 $\mathbf{q}$ 与可访问块的 $\mathbf{k}$ 做点积，得到匹配分数；softmax 将分数变成权重。权重越大，相应块对当前块的影响越大。

## 4. 注意力输出与多头

每个头用权重对其他块的 $\mathbf{v}$ 加权求和，得到该头的输出。多头就是并行进行多套这样的计算，各头使用不同的映射矩阵；它们可能学到不同的关联方式，但不保证每个头都对应一个可命名的语义。各头结果随后拼接、投影，并通过残差连接更新块的表示。

## 5. CLS 分类 token

CLS 是额外加入序列的可学习向量，不是视频里的真实图像块，也不是类别标签。它参与注意力，逐层接收视频块传来的信息；最后一层的 CLS 表示被用作整段视频的表示，再输入分类 MLP 预测类别。

## 6. 五种注意力的区别

主要区别是：当前块可以和哪些块计算注意力。

- **S（空间注意力）**：只看同一帧的空间块。
- **ST（联合时空注意力）**：一次看所有帧中的所有块。
- **T+S（分解时空注意力）**：先沿时间看相同空间位置，再看同一帧的空间块。
- **L+G（稀疏局部—全局注意力）**：分别看局部邻域和稀疏采样的全局位置。
- **T+W+H（轴向注意力）**：依次沿时间、宽度和高度方向计算。

## 7. 训练时“学”的是什么

$W_Q,W_K,W_V$ 等矩阵是模型参数，由训练调整。具体视频上的 $\mathbf{q},\mathbf{k},\mathbf{v}$ 和注意力权重，则是这些参数处理该视频后算出的结果。训练通过最终分类误差，让整套计算逐渐更有助于完成分类任务。
